# 💬 ChatFlow Messenger

سیستەمێکی پێشکەوتووی گفتوگۆ و ماسنجەری ڕاستەوخۆ (Real-time) بۆ کۆمپانیا و شوێنی کار، کە پشت دەبەستێت بە **Microsoft SQL Server**.

---

## 🚀 تایبەتمەندییە سەرەکییەکان
- 👥 **چاتی گرووپی گشتی**: چاتکردنی بەکۆمەڵ بۆ سەرجەم فەرمانبەران و بەکارهێنەران.
- 🔒 **چاتی تایبەتی پارێزراو**: گفتوگۆی تایبەت و ڕاستەوخۆ لەنێوان هەر بەکارهێنەرێک و ئادمین، یان بەکارهێنەران لەگەڵ یەکتر.
- 💾 **پاراستنی نامەکان لە داتابەیس**: هەموو تێکست و فایلەکان لەناو خشتەکانی SQL Server بە هەمیشەیی دەمێننەوە و قابیلی سڕینەوە نین.
- 📎 **ناردنی وێنە و دۆکیۆمێنت**: پاڵپشتی ئاپلۆدکردنی هەموو جۆرە وێنەیەک (PNG, JPG, GIF, WebP) و دۆکیۆمێنتەکان (PDF, Word, Excel, ZIP, RAR).
- 🖥️ **بەرنامەی دێسکتۆپ (Windows Desktop App)**: یەک فایلی ئینستالەر (.exe) کە بە یەک کلیک لەسەر دێسکتۆپی هەموو بەکارهێنەران دادەمەزرێت.
- ✍️ **نیشاندەری نووسین (Typing Indicator)**: نیشاندانی کاتی نووسینی نامە.
- 🟢 **دۆخی بەردەستبوون (Online Status)**: بینینی کەسانی سەرهێڵ و ئۆنلاین لەناو سیستمەکە.
- 🔔 **ئاگادارکردنەوە (Notifications)**: ئاگادارکردنەوە لە کاتی هاتنی نامەی نوێ.

---

## 🛠️ تەکنەلۆژیاکان
- **زمان و ژینگە**: Node.js & Express.js
- **پەیوەندی ڕاستەوخۆ**: Socket.IO
- **داتابەیس**: Microsoft SQL Server (mssql / tedious)
- **ڕووکار (Desktop)**: Electron.js
- **شفرەکردن و ئاسایش**: JWT (JSON Web Tokens) و bcryptjs
- **ئاپلۆد**: Multer v2

---

## 🗄️ خشتەکانی داتابەیس (Database Tables)
داتابەیسی **ChatAppDB** لەخۆگری ئەم خشتانەیە کە خۆکارانە لە کاتی دەستپێکردندا دروست دەبن:
1. `users`: تۆماری زانیاری بەکارهێنەران، وشەی نهێنی هاشکراو، و دەسەڵاتی ئادمین.
2. `group_messages`: هەموو نامە و فایلە هاوپێچکراوەکانی چاتی گرووپ.
3. `private_messages`: نامە تایبەتەکان بە جیاوازی لەنێوان بەکارهێنەران و ئادمیندا.
4. `user_sessions`: بەڕێوەبردنی کەسانی ئۆنلاین و دوایین چالاکی.

---

## 👤 هەژمارەکانی چوونەژوورەوەی سەرەتایی
- **ئادمین (Admin)**:
  - یوزەرنەیم: `admin`
  - وشەی نهێنی: `Admin@123456`
- **بەکارهێنەر (User)**:
  - یوزەرنەیم: `NA`
  - وشەی نهێنی: `123456`
- **تۆمارکردنی نوێ**: هەر بەکارهێنەرێک دەتوانێت لە پەڕەی سەرەکی بە تابی **تۆمارکردن** ئەکاونتی نوێ دروست بکات.

## 📦 دامەزراندن و کارپێکردن

### ١. دامەزراندنی پێداویستییەکان
```bash
npm install
```

### ٢. دەستپێکردنی سێرڤەر
```bash
npm start
```

### ٣. دروستکردنەوەی فایلی ئینستالەری دێسکتۆپ (.exe)
```bash
npm run build:win
```
فایلی ئینستالەر لە فۆڵدەری `dist/` بەرهەم دەهێنرێت بە ناوی:
`ChatFlow Messenger Setup 1.0.0.exe`
